Frontend Requirements

This is a Node.js / Next.js project. Do not run pip install against this file.
The actual npm dependency source is package.json and package-lock.json.

Runtime:
- Node.js >= 20.9.0
- npm included with Node.js

Main dependencies:
- Next.js 16.2.7
- React 19.2.4
- React DOM 19.2.4
- NextAuth 4.24.14
- lucide-react 1.18.0
- TypeScript 5
- Tailwind CSS 4
- ESLint 9

Setup:
1. Copy .env.example to .env.local.
2. Fill local NextAuth, Keycloak, and optional SMTP values.
3. Install dependencies:
   npm install
4. Start development server:
   npm run dev
5. Open:
   http://localhost:3000

Validation:
- npm run lint
- npm run build

Do not share a real .env.local file because it contains secrets.
